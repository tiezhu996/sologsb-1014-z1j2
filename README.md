# 格致 · 数学证明步骤编写与检查工具

一个完全在浏览器运行的数学证明工作台。使用步骤、引用和推理规则组织证明，实时检查结构与符号，并保留版本快照。

## 功能

- 逐步录入前提、推导和结论，选择推理规则并维护步骤引用。
- 检查未定义符号、缺失引用、循环引用和未证明目标。
- 为步骤记录旁注、反例和替代分支。
- 公式快捷输入、KaTeX 实时渲染、原生拖拽排序与键盘导航。
- 文档级撤销/重做，`localStorage` 自动保存，多版本文档管理。
- 保存版本快照并进行逐步差异比较。
- 导出 Markdown 或 LaTeX 证明稿。
- 读回群里改过的稿件：粘贴或选择导出稿即可恢复标题、目标、步骤类型、推理规则、旁注、反例与替代分支，依据序号按稿面编号重新对齐到真实步骤；读不懂的段落整段原样保留，不会因一处解析失败丢弃整篇。

## 技术栈

- Mithril 2
- TypeScript
- Bulma
- KaTeX
- Vite

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开终端输出的开发地址。数据保存在当前浏览器的 `localStorage` 中。

## 读回稿件

标题栏右侧「⤓ 读回稿件」支持 Markdown、LaTeX 和纯文本：

- `## 1. 命题`、`步骤 2：…`、`3) …` 等编号写法都能识别为步骤。
- 「类型 / 推理规则 / 依据 / 旁注 / 反例 / 替代分支」及其常见同义词（类别、规则、引用、备注等）会归入对应字段；类型与规则支持中英写法，未知规则按原文保留。
- 依据中的「步骤 1、步骤 3-5、第 3 步」会重新对到恢复后的真实步骤；指向不存在步骤的引用不会丢失，而是留在该步旁注中并给出提示。
- 解析前会显示预览与逐条提示，确认后作为**新文档**导入，可用撤销恢复原状态。
- 无法识别的段落会原样保留为可编辑步骤，不会因为局部读不懂而丢弃整篇。

解析器测试（编号重映射、缺失引用、乱段保留、LaTeX 往返等）：

```bash
npm test
```

```bash
npm run build

```

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd + Enter` | 添加推导步骤 |
| `Ctrl/Cmd + Shift + Enter` | 添加结论步骤 |
| `Alt + ↑ / ↓` | 切换当前步骤 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 立即保存 |
| `Delete` | 删除当前步骤（编辑框外） |

## Docker

镜像内由 nginx 监听容器端口 `80`，不包含或硬编码宿主端口。

```bash
docker build -t math-proof-editor .
docker run --rm -p 10014:80 math-proof-editor
```

宿主端口 `10014` 仅用于本地运行示例，实际编排端口以根端口表为准。
